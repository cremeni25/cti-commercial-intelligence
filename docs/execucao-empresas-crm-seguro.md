# Execução — Empresas com responsabilidade separada

Regra operacional desta execução:

- pesquisar cliente/empresa continua permitido para prospecção e uso comercial;
- CNPJ e cadastro mestre não são tratados como propriedade exclusiva de vendedor;
- CRM em curso (oportunidades, propostas, pedidos e atividades) é filtrado pelo responsável autenticado para perfis regionais;
- ADMIN_MASTER e DIRETOR_VIENA_SP com acesso total mantêm visão consolidada;
- edição cadastral continua regida pela permissão `clientes_editar`;
- a execução não altera dados comerciais nem transfere responsáveis.
